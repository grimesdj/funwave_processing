# Bowen Nonlinear Rip-Current Solver

## Files

| File | Description |
|---|---|
| `ripchannel_bowen_nonlinear.m` | Main solver. Uses pseudo-time iteration to solve the steady, nonlinear, depth-averaged shallow-water equations. |
| `ripchannel_bowen_nonlinear_example.m` | Example driver for a `spreadRip` / `barRip1` case. Edit `runBATHY`, `gridName`, and `runWAVES` to select another case. |
| `ripchannel_theory_circulation.m` | Required wave-transformation and radiation-stress routine from the previous step. The nonlinear solver calls this function to obtain the directional wave field and radiation-stress tensor. |

## Model equations

Let d(x,y) be the still-water depth, $\eta$ the mean water-level anomaly, $H=d+\eta$, and $\mathbf{U}=(u,v)$. The iterated equations are

```math
\frac{\partial \eta}{\partial \tau}
+\nabla\cdot(H\mathbf{U})=0,
```

```math
\frac{\partial \mathbf{U}}{\partial \tau} +(\mathbf{U}\cdot\nabla)\mathbf{U}=-g\nabla\eta-\frac{1}{\rho H}\nabla\cdot\mathbf{S}-\frac{c_L}{H}\mathbf{U}+\nu\nabla^2\mathbf{U}.
```

Here, $\mathbf{S}$ is the wave radiation-stress tensor. Its divergence is computed from `Sxx`, `Sxy`, and `Syy`, as provided by `ripchannel_theory_circulation.m`.

The nonlinear advective terms are retained. In a steady, converged solution, the pseudo-time derivatives vanish, and the solver satisfies the steady continuity and momentum balances.

## Numerical method and boundary conditions

The solver advances conservative perturbation variables using local Lax–Friedrichs/Rusanov face fluxes. The hydrostatic reference pressure flux is subtracted using the fixed bathymetry $d$; this preserves the zero-flow rest state over the nonuniform bed.

The algorithm uses explicit pseudo-time relaxation with both a CFL and a viscous time-step restriction.

Boundary conditions and wetting/drying treatment:

- **Alongshore:** Periodic, consistent with the periodic channel bathymetry generated by `make_ripchannel_bathy.m`.
- **Wet/dry cells:** Fixed from the supplied bathymetry using `hmin`. Fluxes across dry faces are set to zero.
- **Cross-shore:** Closed boundaries, with an offshore sponge that damps the flow and mean-level anomaly toward zero near the offshore edge.

### Friction options

Bowen's paper presents linear bottom-friction and horizontal eddy-viscosity closures as alternatives. Select one using `opts.friction`:

| Option | Description |
|---|---|
| `'bottom'` | Linear bottom-drag formulation (default), using the depth-averaged term $-c_L\mathbf{U}/H$. |
| `'eddy'` | Horizontal eddy viscosity, using $\nu\nabla^2\mathbf{U}$. |
| `'both'` | Both terms together; provided only as a sensitivity experiment. |

## Important scope and limitations

1. This is a nonlinear numerical extension based on Bowen's equations (19)–(28), not a line-by-line reproduction of Bowen's idealized analytical solution. It solves the coupled steady shallow-water mass and momentum equations, retaining the nonlinear advection discussed by Bowen.
2. The directional wave transformation and radiation stress are supplied by the preceding reduced wave routine. That routine treats directional bins independently and does not solve a full two-dimensional spectral wave-action/ray equation. Directional spreading therefore changes the stress field, but lateral ray convergence and focusing are not explicitly represented.
3. The model is steady and depth averaged. It does not resolve individual waves, surfbeat, vertical structure, wave–current feedback on the wave field, morphodynamics, or moving wet/dry boundaries.
4. The offshore sponge and closed cross-shore edge are numerical boundary choices. Check sensitivity to `spongeFraction`, `spongeStrength`, and domain length before interpreting offshore circulation quantitatively.
5. Check `convergenceHistory` and `out.converged`. Failure to converge should not be interpreted as a physical unsteady solution. Adjust `maxCells`, `cfl`, `relax`, friction, and `maxIter`, and inspect sensitivity.
6. A MATLAB/Octave runtime was not available to execute this package in the creation environment. Validate the code first on a simple planar beach and a modest grid before running the full parameter space.

## Suggested initial settings

```matlab
opts.friction = 'bottom';
opts.bottomDrag = 0.02;     % [m/s], tune to the current scale
opts.nu = 2.0;              % [m^2/s], used when friction='eddy' or 'both'
opts.maxCells = 80000;
opts.cfl = 0.30;
opts.maxIter = 60000;
opts.tol = 1e-6;
```
